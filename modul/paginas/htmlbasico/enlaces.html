Crear enlaces en html

  1. La etiqueta a se utiliza para crear enlaces a otras paginas web, documentos o secciones dentro de la misma pagina
  2. El elemento esencial para otros enlaces es href que define la URL a la cual redigirige al usuario

Atributos de los enlaces

  • href (hypertext reference): define la URL de destinación de enlace. Puede ser absoluta
  • target: Define donde se abrirá en enlace, en la misma pestaña o una nueva
    • _blank: abre el enlace en una nueva pestaña
    • _self: abre el enlace en la misma pestaña
