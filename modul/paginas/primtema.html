HTML BASICO

¿QUÉ ES HTML?

(HyperText Markup Language) es el lenguaje de marcas para crear páginas web.

ESTRUCTURA GENERAL

Un documento HTML se basa en una estructura jerárquica de etiquetas que definen las diferentes partes de una página.

Cada página HTML sigue una estructura similar, empezando por el DOCTYPE seguido de las etiquetas html, head, body.

ETIQUETAS BÁSICAS

  • title
  • h1 a h6: para títulos y subtítulos
  • p: para parrafos
  • br: para forzar una nueva linea
  • & nbsp: insertar un espacio en blanco

ELEMENTOS HTML Y ANIDAMIENTO

Diferencia entre etiquetas y elementos

Etiqueta (tag):

Es la parte que define el inicio y el final de un componente en HTML.

Se delimita con simbolos.

Elemento:

Un elemento incluye la etiqueta de apertura, el contenido y la etiqueta de cierre.

Los elemetnos pueden ser vacios o contener otros elementos dentro.

ATRIBUTOS HTML

Los atributos en HTML son elementos que agregan información extra a las etiquetas para modificar el comportamiento o la apariencia. Estos atributos se colocan siempre dentro de una etiqueta abierta y seguiendo el formato nombre=valor"

FORMATO DE TEXTO

  • b y strong para negrita
  • i y em para cursiva
  • u para subrallar
  • strike o s para rallar texto
  • sup para superindíce
  • sub para subindice
